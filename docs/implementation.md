# Belarus family trip

Goal: publish the requested public mobile family itinerary on Vercel, connected to GitHub.
Architecture: static HTML, CSS and a small browser module. Node build renders curated trip data into HTML; no runtime dependencies, server, database or sign-in.

- Research official attraction/booking pages and restaurant availability in parallel.
- Build six anchored day timelines, route graphic, hotel cards and booking priorities.
- Provide three restaurant choices for every lunch and dinner; disclose unverified availability and itinerary conflicts.
- Test trip dates in Europe/Minsk, links, restaurant coverage, responsive layout and browser errors.
- Create repository, connect Vercel, push, deploy production and verify anonymous access.

Design: warm paper background, forest green navigation and Yandex actions, restrained orange priority markers; large touch targets, accessible native details for restaurant choices. No external fonts or image dependencies.
