# Беларусь — семейная поездка 4–9 октября 2026

Публичный mobile-first маршрут: шесть дней, отели, рестораны, Яндекс Карты, билеты и приоритеты бронирования. Статический сайт без runtime-зависимостей, базы данных и авторизации.

## Запуск

Требуется Node.js 22+ и Python 3 для локального сервера.

```sh
npm run build
npm test
npm run dev
```

Открыть http://localhost:4173.

## Редактирование

- `trip.mjs` — дни, места, отели и бронирования.
- `restaurants.json` — ресторанные варианты, источники, замечания.
- `scripts/build.mjs` — сборка статического HTML.
- `public/styles.css` — адаптивные стили.
- `public/app.mjs`, `public/date.mjs` — «Сегодня» по Europe/Minsk и подсветка навигации. Дата обновляется каждую минуту и при возвращении во вкладку.

Маршрут, ссылки и ресторанные карточки работают без JavaScript; автоматический блок «Сегодня» требует JavaScript. Статусы экскурсий не означают подтверждённую бронь. Исследование источников — `research-attractions.md`. Страница не собирает персональные данные.

## Vercel

Production branch: `main`. Build command: `npm run build`. Output: `dist`. Настройки в `vercel.json`. Проект подключён к GitHub; изменения `main` публикуются через интеграцию Vercel.

## Поддержка

Это личная статическая памятка, не сервис бронирования. Исправления вносятся в указанные файлы и публикуются новым commit. Для аварийного отката использовать предыдущий готовый deployment в Vercel. Отдельные аккаунты, intake, аналитика и инфраструктура поддержки исключены из заданного простого публичного MVP.
